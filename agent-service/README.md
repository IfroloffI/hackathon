# agent-service — живые реплики NPC через локальную LLM

Слушает `ws://<сервер>:2567/llm/stream` (контракт `chronolet.llm/1`, [docs/LLM_CONTRACTS.md](../docs/LLM_CONTRACTS.md)),
генерирует реплики рассказчиков эпох и ХРОНОСа через Ollama (`qwen2.5:3b`) и отвечает через `/llm/say`, `/llm/hint`, `/llm/memory`.
**Правила игры не решает** — только слова. Игра от сервиса не зависит: нет ответа в срок — сервер говорит заготовку.

## Запуск

```bash
npm run build && npm start          # игровой сервер на хосте (:2567)
docker compose up -d                # Ollama + модель + agent-service (первый раз — с интернетом, ~2 ГБ)
docker compose logs -f agent-service
```

Без Docker: `ollama serve`, `ollama pull qwen2.5:3b`, `npm start -w agent-service`.
На Mac нативная Ollama (Metal) в разы быстрее Docker (только CPU):
`OLLAMA_URL=http://host.docker.internal:11434 docker compose up -d agent-service`.

## На что реагирует

| Событие | Кто говорит | Что делает модель |
|---|---|---|
| `agent.ask` (E у рассказчика, «@Галилей …» в чате) | рассказчик / ХРОНОС | отвечает игроку с учётом цели шага и памяти о нём |
| `puzzle.failed` с `data.hint` | ХРОНОС | **перефразирует подсказку партии** (числа обязаны сохраниться, иначе — заготовка) |
| `puzzle.failed` без подсказки | ХРОНОС | реагирует на ошибку, не раскрывая ответ |
| `puzzle.stage`, `puzzle.solved` | ХРОНОС | отмечает прогресс, подталкивает дальше |
| `idle` | ХРОНОС | подкалывает того, кто стоит (не чаще раза в 10 с на сессию) |

Остальное (вход в эпоху, роли, брифинг) озвучивает сервер заготовками — сервис молчит, двух голосов нет.

## Как укладываемся в тайминги на CPU (6–15 ток/с)

- **Захват сразу** (пустой кусок с `replyTo` — у игрока «печатает…»), дальше текст идёт кусками раз в 250 мс.
- Нет первого токена за `FIRST_TOKEN_MS` (4 с) — **отказ** (пустой финал): сервер сразу говорит заготовку.
- Ollama недоступна — отказ без генерации, заготовка звучит мгновенно.
- Короткий промпт: стабильная персона первым сообщением (кэш префикса в Ollama), данные и задача — в конце; `num_predict` 70.
- Одна генерация за раз, очередь с приоритетами (вопрос → ошибка → этап → простой); устаревшие задачи выбрасываются.

```
[agent] #812 puzzle.failed ship_ai hint=1 source=llm ttft=1430ms total=5210ms tok=38 «…»
```

## Переменные

| | По умолчанию | |
|---|---|---|
| `SERVER_URL` | `http://127.0.0.1:2567` (в compose — `http://host.docker.internal:2567`) | игровой сервер |
| `LLM_SERVICE_TOKEN` | `dev-llm-token` | тот же, что у сервера |
| `OLLAMA_URL` / `OLLAMA_MODEL` | `http://127.0.0.1:11434` / `qwen2.5:3b` | |
| `FIRST_TOKEN_MS` | 4000 | срок до первого токена |
| `MAX_TOKENS` | 70 | длина реплики |
| `PROACTIVE_GAP_MS` | 10000 | пауза между инициативными репликами |
