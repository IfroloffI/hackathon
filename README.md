# Колизиум

Кооперативная 2.5D-игра в браузере. Дизайн — [docs/chronolet-design.md](docs/chronolet-design.md), архитектура — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), спецификация — [docs/SPEC.md](docs/SPEC.md), **контракт для LLM-сервиса — [docs/LLM_CONTRACTS.md](docs/LLM_CONTRACTS.md)**.

**Один хост:** всё (сайт, WebSocket, БД, позже LLM) крутится на одной машине. Остальные ноутбуки в LAN только открывают браузер.

## Требования

- Node.js ≥ 22.13 (в `package.json` закреплён через Volta; без Volta — `nvm use 22`).
- SQLite встроен в Node (`node:sqlite`). Временные ряды — **DuckDB** (`@duckdb/node-api`, готовые бинарники под macOS/Linux): `npm install` нужно сделать **заранее, с интернетом**, на той машине, что будет хостом.

## Запуск

### Всё одной командой (Docker)

```bash
npm run up      # игра + LiveKit (голос) + Ollama + agent-service; = scripts/up.sh
npm run down    # остановить
docker compose logs -f game agent-service
```

`scripts/up.sh` берёт LAN-IP хоста для голоса (`LIVEKIT_NODE_IP`), при необходимости создаёт dev-сертификат в `livekit/certs` и выполняет `docker compose up -d --build`. Игра откроется на `https://localhost:2567`, с других ноутбуков — на `https://<ip-хоста>:2567`. Сертификат самоподписанный: в браузере один раз нажать «Перейти», для голоса то же сделать на `https://<ip-хоста>:7880`. БД и временные ряды хранятся в `./data`, как при `npm start`, поэтому одновременно с `npm start`/`npm run dev` стек не запустится: база и порт 2567 общие.

Первый запуск нужен с интернетом: образы и модель (~2 ГБ), дальше работает офлайн. Порты: 2567 (игра), 7880 (wss LiveKit), 7881/tcp и 50000–50100/udp (медиа), 11434 (Ollama). Поиск публичных комнат по UDP-маякам из контейнера в LAN не работает — входите по коду. На Mac Ollama в Docker идёт без GPU; быстрее нативная: `OLLAMA_URL=http://host.docker.internal:11434 npm run up -- game livekit livekit-tls agent-service`.

### Без Docker

```bash
npm install

# Разработка: сервер :2567 (tsx watch) + Vite :5173 с HMR
npm run dev
# → http://localhost:5173, с других ноутбуков http://<ip-хоста>:5173

# «Боевой» режим на хакатоне: один процесс, один порт
npm run build && npm start
# → http://<ip-хоста>:2567
```

Проверки:

```bash
npm test                          # юнит-тесты: физика и проходимость уровней (shared), головоломки, сценарии, DuckDB (server)
npm run smoke -w server           # мультиплеер: комнаты, синхронизация, БД (сервер запущен)
npm run playthrough -w server     # два бота проходят все 5 эпох до финала: сценарии, XP, ачивки, магазин, ряды (сервер запущен)
npm run llm-contract -w server    # проверка контракта realtime-LLM (сервер запущен)
npm run llm-mock -w server        # образец LLM-сервиса: подписывается на поток и отвечает шаблонами
LLM_EXTERNAL=1 npm run llm-contract -w server   # контракт против настоящего agent-service
```

### Живые реплики NPC (локальная LLM)

```bash
npm run up                                   # весь стек, включая Ollama + qwen2.5:3b + agent-service (первый раз — с интернетом, ~2 ГБ)
docker compose logs -f agent-service         # source=llm|fallback|timeout, ttft, total по каждой реплике
docker compose stop ollama                   # игра продолжает работать на заготовках
```

Подробности — [agent-service/README.md](agent-service/README.md) и [docs/LLM_CONTRACTS.md](docs/LLM_CONTRACTS.md).

```bash
npm run udp-listen -w server      # слушатель UDP-маяков публичных комнат
```

В `npm run dev` включён `CHRONOLET_SOLO=1`: один игрок может занять обе роли — удобно тестировать в одиночку. В `npm start` (хакатон) головоломки строго на двоих.

## Что уже есть

- Лобби: имя → токен (`POST /auth/login`, хранится в localStorage), создание комнаты через RoomManager (`POST /room`) с тоглом публичности, вход по коду или из списка открытых комнат, ссылка-приглашение `/?room=CODE`.
- Кнопка «Скопировать приглашение» в игре: ссылка всегда с LAN-IP хоста (даже если хост открыл игру как localhost) — её можно сразу кидать в чат.
- Комната-экипаж на Colyseus: до 6 игроков, синхронизация движения (клиент шлёт 20 Гц, сервер проверяет скорость/границы и рассылает патчи 20 Гц), интерполяция чужих игроков, чат, переподключение (20 с).
- SQLite: игроки, сессии, прогресс (эпоха, детали, роли), позиции (пачкой раз в 5 с и при выходе; при перезаходе в ту же комнату игрок появляется там же), журнал событий.
- Публичные комнаты (тогл в лобби) маячат по UDP: пакет уходит на `255.255.255.255`, на directed broadcast подсети (например `172.16.215.255`) и на `127.0.0.1` — на macOS broadcast не заворачивается в loopback, поэтому копия на loopback гарантирует, что слушатель на том же маке тоже увидит маяк. Проверка: `npm run udp-listen -w server`.
- three.js: 2.5D-сцены, твёрдая 3D AABB-физика платформера (бег, прыжки, глубина W/S).
- **Полосы препятствий:** до ролей в каждой эпохе — ямы (падение → ближайший чекпоинт), уступы, платформы только в дальнем ряду (W) и стены-лабиринты, обходимые по глубине. Тест `shared/src/reachability.test.ts` перебирает действия игрока на настоящей физике и доказывает: до каждой роли и каждой сферы можно добраться и вернуться к кораблю, а простой ходьбой до ролей не дойти.
- **VK Coin:** 44 сферы на уровнях (4 на борту + по 8 в эпохах). Подбор засчитывает сервер — монету получает первый коснувшийся. Кошелёк и купленные скины хранятся в БД (`player_profile`) между сессиями.
- **Маскоты ВК в магазине** у синего терминала на борту (E): Спотти, Персик, Глазки, Спаркс, Сеня, Дигги (три последних — черновой облик, сверить с брендбуком), Лайкоша, Хронавт VK. Покупка и примерка проверяются сервером, скин видят все.
- **Дизайн в духе VK:** светлое лобби на VKUI-подобных токенах (#0077FF, карточки, ячейки, рейтинг), тёмный HUD поверх 3D: аватар, уровень и шкала XP, цель сценария с таймером, экипаж с лайками, стикеры, снекбары.
- **Геймификация:** XP и уровни, 13 ачивок (+ монеты), лайки экипажу (❤ в списке, кулдаун 15 с), стикеры над головой (1–6), бонусы эпох (все сферы, без падений, без подсказок, ≤2 ошибок), бонус за контрольное время шага, рейтинг хронавтов (`GET /api/leaderboard`).
- **Сценарии эпох** (`shared/src/scenarios.ts`): брифинг у учёного → путь к ролям → этапы головоломки → эвакуация. Роли закрыты до брифинга, у шагов контрольное время. Головоломки стали сложнее: случайные параметры, счёты и подтверждение у Эратосфена, облака и спутники Юпитера у Галилея, ветер и две мишени у Ньютона, два перехвата Энигмы, случайные корабль и стол у Королёва.
- **Временные ряды (DuckDB, `data/chronolet.duckdb`):** все события и телеметрия позиций ~5 Гц, агрегаты `time_bucket`; поток событий и REST для realtime-LLM (`/llm/*`, см. контракт).
- **Стиль «рукодельной диорамы»** (картон, фетр, вязка, швы; `client/src/game/craft.ts`): эпохи — диорамы со слоями-вырезками и кочками на переднем плане, борт Колизиума с иллюминаторами и двигателем-«бочкой», персонажи — мягкие вязаные фигурки с глазами-пуговицами и squash & stretch, монеты VK — пришитые пуговицы.
- **Полоса препятствий** (`shared/src/mechanics.ts`, данные — в `Level.crates/fans/arrows` и `kind` платформ): толкаемые ящики (позиции считает сервер, 30 Гц; станция «вернуть ящики» сбрасывает тупик), батуты (подброс ≈5), вентиляторы по таймеру (любой твёрдый объект и ящик — укрытие), самострелы (стрела или ров — назад к чекпоинту), флажки чекпоинтов. Каждая эпоха — ~130 ед. трассы: одна роль на полпути, вторая в конце (~5 мин на экипаж из 4). Цвет канта = действие: оранжевый — толкать, розовый — пружинить, голубой — поток, красный — опасно, жёлтый — лазать (верёвка, пока только вид).
- **Паркур-отсек на корабле** — за переборкой справа от палубы: ящик → мостки под стрелами → батут → ярус под порывами. Финиш даёт +5 VK Coin каждому игроку раз за сессию (станция `reward`).
- **Проходимость проверяется тестами** (`shared/src/reachability.test.ts`): обход на настоящей физике (с батутами) доходит до всех станций и монет при ящиках на задуманных местах, без ящиков — нет; каждый ящик доезжает до места, роли не стоят под ветром и стрелами.
- **Витрина стиля** (dev): `http://localhost:5173/showcase.html` — объекты, все скины и любой уровень без сервера; уровень можно пройти самому (WASD + пробел, `&x=` — старт с нужного места).
- **Песочница головоломок** (dev): `http://localhost:5173/sandbox.html` — настоящие головоломки в браузере, оба экрана ролей рядом.
- **Игровой цикл:** борт Колизиума → рычаг прыжка → эпоха → головоломка на двоих → деталь → «все на борт» у приземлившегося Колизиума → деталь загорается в двигателе → следующая эпоха → после 5 деталей финал.
- **Пять эпох и головоломок** (chronolet_ideas.docx), у каждой роли свой экран и свои данные:
  | Эпоха | Наблюдатель видит | Механик управляет | Деталь |
  |---|---|---|---|
  | Сиена и Александрия | расстояние, «тени нет» | дугой гномона (видит тень) | Гномон |
  | Падуя, 1610 | фазу Венеры в телескопе | моделью: схема, положение Венеры | Линза |
  | Англия, 1687 | мишень и траектории | скоростью и углом пушки | Маятник |
  | Блетчли-парк, 1941 | перехват и WETTERBERICHT | тремя роторами (видит таблицы) | Ротор |
  | Байконур, 1961 | формулу, телеметрию | ступенями ракеты (видит массы) | Топливный элемент |
- Роли занимаются клавишей E у светящихся кругов; рассказчики эпох и бортовой ИИ ХРОНОС говорят заготовленными репликами и помнят, что уже рассказали игроку (`agent_memory`); подсказки ХРОНОСа растут с числом ошибок (намёк → направление → почти ответ).

## HTTP API (Fastify, один порт 2567)

HTTP-слой переписан на **Fastify**: один `node:http`-сервер обслуживает и REST, и оба WebSocket-канала (Colyseus + hello). Express из пользовательского кода удалён — пакет остался только как зависимость `@colyseus/ws-transport` (статический импорт внутри транспорта).

### Auth

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| POST | `/auth/register` | `{ name, password }` | `201 { token, player }`; `409` — логин занят; `400` — логин 3–20 символов (буквы, цифры, пробел, _ -), пароль 6–72 |
| POST | `/auth/login` | `{ name, password }` | `200 { token, player: { id, name } }`; `401` — «Неверный логин или пароль» |
| POST | `/auth/password` | `{ oldPassword, newPassword }` (Bearer) | `{ ok: true }` |
| POST | `/auth/logout` | — (Bearer) | `{ ok: true }` — токен уходит в in-memory blacklist |
| GET | `/auth/me` | — (Bearer) | `{ player: { id, name } }` |

Токен передавать как `Authorization: Bearer <token>`. Пароли — scrypt с солью (`server/src/auth/passwords.ts`), не больше 10 попыток входа в минуту на «IP + логин». Аккаунт из времён входа «по имени» (без пароля) можно один раз забрать регистрацией — прогресс сохранится. Без `JWT_SECRET` секрет генерируется один раз и хранится в `data/.jwt-secret` (токены переживают перезапуск). **В комнату пускают только с токеном** — имя игрока берётся из токена, а не из параметров клиента.

### RoomManager (роли: мастер = создатель, гости)

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| POST | `/room` | `{ crewName?, isPublic? }` (Bearer) | `201 { roomId, crewName, hostPlayerId, hostName, isPublic, clients, maxClients, createdAt }` |
| GET | `/room/:id` | — (Bearer, только мастер) | `ManagedRoomInfo` |
| DELETE | `/room/:id` | — (Bearer, только мастер) | `204` — грейсфул-удаление комнаты |
| POST | `/room/:id/disconnect` | — (Bearer) | `{ closed: <n> }` — закрыть WS-каналы игрока в комнате |

Публичная комната (`isPublic: true`) бродкастится по LAN: UDP-пакет `{ app: 'chronolet', roomId, crewName, host, port, ts }` на `255.255.255.255:41234` каждые 1.5 с. Посмотреть бродкасты:

```bash
npm run udp-listen -w server
```

### WebSocket

| Канал | Назначение |
|---|---|
| `ws://…/<processId>/<roomId>?sessionId=…` | Colyseus state-синхронизация (как раньше, через SDK) |
| `ws://…/room/{id}/connect?token=<jwt>` | hello-канал: сервер раз в секунду шлёт всем `{"type":"hello","text":"Hello world!","ts":…}` |

### Matchmake

`POST /matchmake/:method/:roomName` (`create`, `join`, `joinOrCreate`, `joinById`, `reconnect`) — wire-контракт `@colyseus/sdk` сохранён, черновик клиента работает без правок.

## Переменные окружения (server)

| Переменная | По умолчанию | |
|---|---|---|
| `PORT` | `2567` | порт единственного хоста |
| `HOST` | `0.0.0.0` | слушать на всех интерфейсах (LAN) |
| `DB_PATH` | `data/chronolet.db` | файл SQLite |
| `JWT_SECRET` | — | секрет JWT; не задан — случайный на запуск |
| `JWT_TTL` | `7d` | время жизни токена (формат `jose`) |
| `UDP_BROADCAST_ADDR` | `255.255.255.255` | адрес UDP-бродкаста (`127.0.0.1` для локальной проверки) |
| `UDP_PORT` | `41234` | порт UDP-бродкаста |
| `UDP_INTERVAL_MS` | `1500` | период beacon'а |
| `OLLAMA_ENABLED` | — | `1`, чтобы включить LLM (пока заглушка) |
| `OLLAMA_URL` / `OLLAMA_MODEL` | `http://127.0.0.1:11434` / `qwen2.5:7b-instruct` | |
| `DEBUG_EVENTS` | — | `1` — логировать события шины |
| `CHRONOLET_SOLO` | — | `1` — один игрок может держать обе роли (в `npm run dev` включено) |
| `TSDB_PATH` | `data/chronolet.duckdb` | файл временных рядов DuckDB |
| `LLM_SERVICE_TOKEN` | `dev-llm-token` | сервисный токен LLM для `/llm/*` и `/llm/stream` — **смените на хакатоне** |

Отладочные эндпоинты: `GET /api/host` (LAN-адреса хоста), `GET /api/rooms` (+ `isPublic`), `GET /api/managed-rooms` (Bearer), `GET /api/sessions`, `GET /api/sessions/:code` (позиции игроков из БД).
